    What this experiment can establish

    Controller decisions, filter response, logical output duration and fault handling on synthetic traces. It does not measure irrigation volume, water savings, crop yield, sensor accuracy, ESP32 execution latency or MQTT performance.

    The software uses a one-second clock, five-second samples, a five-reading moving average and a 60-second dose window. One command minute lasts one simulation second. Sensor faults are immediate; recovery is sampled at the next five-second tick. The Wokwi firmware can schedule an immediate recovery sample, so recovery timing is not cycle-equivalent.

    Network loss is an in-process transport surrogate with one pending snapshot. While disconnected, the collector keeps its old reading. Older offline snapshots are overwritten; no complete offline history is promised.

    Moisture membership shoulders: 20–50% and 50–80%; triangular normal peak: 50%. Air temperature peaks: 15/27/39 °C; humidity: 30/60/90%. Minimum rule firing and weighted singleton outputs implement a zero-order Sugeno controller. Both controllers use the same filtered input, raw-wet shutdown and fault gate.
