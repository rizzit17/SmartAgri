# Recorded software simulation evidence

These are synthetic software traces, not physical farm measurements. The timestamped folders preserve the run IDs referenced by the screenshot manifests. Each run includes raw JSON and CSV. The experiment folder contains all nine scenarios, comparison values, checks and source hashes. crop-model-metrics.json records the independently evaluated dataset model. Models are re-created with simulator/train_model.py; binary pickle artifacts are excluded.

CSV line endings are normalized to LF for repository storage; numerical records are unchanged.
