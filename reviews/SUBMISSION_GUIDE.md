## Implementation contents

The implementation is an exact committed Git source snapshot: Streamlit dashboard, collectors, dataset and training scripts, browser simulator, ESP32/Wokwi files, dependency specifications, tests, screenshots, raw experimental evidence, reproducibility instructions and the editable research paper. The archive identifies the exact source commit in its repository-link file.

Secrets, local accounts, active sensor snapshots, virtual environments, compiler binaries and generated model pickles are excluded. Train the model using the documented command when needed. The browser control simulation can run with Python's standard library alone.
